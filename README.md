# 今日运势 · Daily Fortune CLI

在 macOS Terminal 或 iTerm2 输入 `今日运势`，即可抽取一张每日短签。默认显示财运、桃花运、事业运的百分制分数，一张原创符卡、一句点评和七颗星。用 `今日运势 --full` 查看七项星级、幸运元素、赛博黄历和寄语。同一匿名用户、同一日期、同一版本得到相同内容，安装后完全离线。

**仅供娱乐。分数、幸运元素和签文都是程序生成值，不预测未来，也不构成健康、投资或关系决策依据。** 赛博黄历借用宜忌的文化形式，不是传统黄历计算器。

## 安装与运行

需要可运行的 **Python 3.9+**。首次安装 Python 时，请选择仍在维护的 macOS 版本。程序使用 Python 标准库，安装到当前用户目录。 [Python macOS 下载](https://www.python.org/downloads/macos/) · [Python 维护状态](https://devguide.python.org/versions/)

在本项目目录执行：

```zsh
./install.sh
今日运势
```

默认安装位置：

| 内容 | 路径 |
| --- | --- |
| 中文命令 | `~/.local/bin/今日运势` |
| 独立程序副本 | `~/.local/share/daily-fortune/app/` |
| 安装清单 | `~/.local/share/daily-fortune/receipt.json` |
| 本地状态 | `~/.local/share/daily-fortune/state/`（匿名标识与每日抽签记录） |

安装后可以移动源码目录，已安装的程序仍能运行。启动器固定使用安装时的 Python 绝对路径；如果之后移除该 Python，请用另一个可用的 Python 卸载，再重新安装。

如果安装器提示命令目录不在 `PATH`，在当前终端执行：

```zsh
export PATH="$HOME/.local/bin:$PATH"
```

希望新终端也生效时，将这一行加入自己的 `~/.zshrc`。安装器不会自动编辑 shell 文件。本次交付环境原本已经配置此路径。

若要指定解释器或在独立目录试装：

```zsh
PYTHON=/绝对路径/python3 ./install.sh --prefix "$HOME/某个测试目录"
```

`--prefix` 的目录不存在时会创建。遇到 PATH 同名可执行命令、已有命令文件、程序目录或清单，会在写入前拒绝安装，避免覆盖或遮蔽。请自行检查冲突，不要用 sudo 或强行覆盖。权限不足会报错；请改用自己可写的目录。

不安装也可从源码运行：

```zsh
./今日运势
python3 -B main.py
```

## 更新

已有安装时，在新版源码目录执行以下命令。自定义过安装位置时，用 `./update.sh --prefix 路径` 指向同一安装目录。

```zsh
./update.sh
今日运势 --version
```

更新会核对已安装文件的清单，验证新版本可运行，然后切换程序副本。匿名标识和抽签记录继续由原目录保存。旧程序和清单保存在更新完成时打印的备份目录。切换失败时会尝试恢复旧版。若遇到断电或进程被强制结束，请保留安装目录和同级的 daily-fortune-backup-* 目录，以便核对后恢复。

## 参数

```zsh
今日运势 --help
今日运势 --version
今日运势 --plain
今日运势 --full
今日运势 --date 2026-11-08
今日运势 --plain --date 2026-11-08
```

短签每天可以抽一次。当天再次运行时会显示一句带颜文字的提醒。每日次数按系统本地日期计算，`--plain` 也计入当天次数。记录保存在本机的状态目录里，关掉终端再打开仍然有效。

`--date YYYY-MM-DD` 可查看指定日期的短签，包括今天。`--full` 随时可看详细报告。这两个选项都不消耗当天的抽签次数。日期使用公历 0001–9999 年。

在终端直接运行时，短签或同日提醒后会出现小菜单。输入 `1` 看详卦，`2` 领当日小任务，或 `3` 输入两个日常选项并随机挑一个。小任务每天固定，二选一的内容只在当前运行中使用。按回车离开。管道、重定向和 `--plain`、`--date`、`--full` 仍直接输出后退出。

短签和详版采用太卜司的口吻，以穷观阵或法眼开卦，自称「本座」，并给出签级与宜忌。短签在常规窗口中占七行，窄窗口会自动换行。交互终端会加粗点评，`--full` 使用详细版的栏目、颜色和标题 Emoji。管道、重定向、`TERM=dumb` 和非空 `NO_COLOR` 自动关闭 ANSI 装饰。`--plain` 将星星显示为 `n/7`，详版则显示为 `n/5`。

短签从原有的三个领域星级派生百分制分数，每星对应 20 分区间。三项平均分决定短签的点评等级与亮星数，分数最高的一项决定符卡主题。详版继续用六个领域计算综合运势。

中文按全角双列处理，组合附加符不单独占列；还处理本程序会用到的常见 Emoji、变体选择符、肤色、ZWJ 与旗帜序列。标准库实现不是完整 Unicode 字素分段器。字体、Unicode 版本和 iTerm2 的模糊字符双列设置仍可能改变星形或线条宽度；因此界面不用封闭表格，遇到差异可使用 `--plain`。极窄窗口仍保留全部内容，中文标点避头规则在足够宽度下生效。

## 调研与原创设计

先研究星座报告、黄历、每日单卡、御神签、幸运元素、开源 fortune 和终端技术，再实现本项目。简要取舍：

- 星座报告：借鉴分领域分类，每项评分配具体建议。
- 黄历：借鉴宜忌形式，改写为现代生活小行动。
- 单卡玩法：借鉴当天意象，让主题、颜色、物品与签文相互呼应。
- 御神签和 fortune：借鉴“等级、短诗、解读”的仪式感，内容全部原创。
- 开源 CLI：借鉴本地内容、标准参数和清晰退出行为，不引入联网或开机自动运行。

完整的多来源链接、实际阅读范围、文化与技术的区别及访问失败记录见 [docs/RESEARCH.md](docs/RESEARCH.md)。没有复制其他网站的运势正文、牌图或开源项目的引文库。

## 每日生成原理

第一次生成报告时，使用系统随机源创建一个 128 位匿名安装标识，文件权限为 `0600`、新建状态目录权限为 `0700`。不读取硬件序列号、网络地址、生辰、姓名或其他设备信息，不收集或上传数据。标识发布采用临时文件加原子硬链接，并发首次运行也会共享同一个完整标识。保存失败或文件损坏时明确报错，不临时更换种子。

算法版本是 `daily-fortune-v1`。基本序列为：

```text
SHA256(UTF8(JSON([算法版本, 匿名标识, ISO日期, 字段标签, 计数器])))
```

JSON 规定使用紧凑分隔符和原始 Unicode；摘要按大端整数读取，再用拒绝采样映射到整数范围。所有计算使用固定整数规则，不用内置 `hash()`，也不依赖 `random.choice()` 的跨版本实现。每个评分、颜色、意象和寄语字段都有独立标签；新增无关字段不会消耗现有字段的序列。

1. 先生成一个公共节奏值与专注、秩序、联结、活力四个偏移；六个领域分别加上对应偏移及独立的小扰动，限制为 1–5 星。这让相关领域略有联系，同时保留差异。这些权重是娱乐设计，不是对人的测量。
2. 综合星级是六项的算术平均，按整数“四舍五入”显示。签等级按未取整的六项总分确定：

| 总分 | 等级 | 本项目含义 |
| --- | --- | --- |
| 6–9 | 凶 | 缓行、核对，不预示灾祸 |
| 10–13 | 末吉 | 留白、整理 |
| 14–17 | 平 | 平常节奏 |
| 18–21 | 小吉 | 积累小进展 |
| 22–25 | 中吉 | 选准重点 |
| 26–30 | 大吉 | 舒展、小步尝试 |

这是本项目的原创顺序与映射，不声称是所有寺社通用的传统。相同的综合星级可能对应不同签级，因为显示星级经过取整。

3. 从最高分领域确定主题；最低分领域提供提醒，平分时用独立标签选择。最高分也可能只有一两星，因此主题使用中性意象。分数 1–2、3、4–5 分别选取收束、平稳、尝试类文案。宜覆盖三个不同领域并匹配各自星级；忌始终是明确的负面行为。寄语引用实际选中的行动和提醒，不另抽一份相冲突的结论。
4. 句段与幸运元素使用“日历洗牌”：对每个固定候选集合，按匿名标识、字段和日期块产生排序，每 N 天遍历 N 个候选；若块交界处首尾重复，只交换新块的前两项。结果不依赖查询顺序，不记录历史，也不通过反复运行刷新。幸运数字在 1–99 中轮换，颜色、关键词与物品来自当天主题。

内容库含 108 条领域建议、90 条宜、36 条忌、36 组双句意象、36 条等级解签，以及多组幸运元素、开头和轻幽默收尾。多样性来自结构与语义约束下的组合。有限内容会再次出现，某项星级连续相同也完全正常；不承诺每天每一句都不同。固定候选池的轮换可避免该池连续日期直接重复，但主题或分数切换后的子池重新进入不作此保证。

复现保证以匿名标识、日期、算法和内容版本相同为前提。更换标识、改变参与评分的规则或编辑某个候选池可能改变对应结果；无关新字段不影响已有字段。保留 `user-id` 可在重装后延续相同版本的结果。源码直接运行可用绝对路径 `DAILY_FORTUNE_HOME` 指定隔离状态目录；已安装启动器固定使用其安装目录内的状态。

## 卸载

在保留的源码目录执行：

```zsh
./uninstall.sh
```

自定义安装根目录时，传入相同的 `--prefix`；若原 Python 已移除，可用 `PYTHON=/另一个/python3 ./uninstall.sh`。卸载只删除清单中完整、校验值吻合的程序文件和启动器，**保留匿名标识及状态目录**，不会修改 PATH 或删除用户数据。文件被改动、缺失、出现未知文件或符号链接时会拒绝删除，请先检查并保留自己的改动。本版本没有强制覆盖或自动清空数据选项。

清单用路径白名单和 SHA-256 约束删除范围，不是防恶意篡改的认证机制。常见权限问题在删除前检查；如果文件被其他程序同时修改或底层文件系统中途出错，仍可能需要人工检查。升级请使用 `./update.sh`。
